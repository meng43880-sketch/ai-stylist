# Расширение «Стилист — сохранить товар» (Chrome/Edge)

Собирает **нашу собственную базу**: находясь на карточке WB/Ozon, жмёшь
«Сохранить в базу» — товар улетает в `POST /api/collect` и попадает в общие
рекомендации. Только явный клик пользователя, никакого тихого сбора.

## Установка (2 минуты)

1. `chrome://extensions` → включи **Developer mode**
2. **Load unpacked** → выбери папку `extension/` из репозитория
3. Нажми на иконку → введи адрес сервера (по умолчанию Render),
   свой логин и пароль из приложения → Войти

## Использование

1. Открой карточку товара на wildberries.ru или ozon.ru
2. Нажми иконку расширения → проверь название/цену → **Сохранить в базу**
3. Готово: товар ищется в ленте всех (`source: 'community'`)

## Что отправляется

Название, цена, фото-URL, бренд, рейтинг, ссылка. Цвета/стили/категорию
сервер выводит сам из названия. Пароль не хранится — только токен сессии.

## Ограничения

- Работает только в десктопном Chrome/Edge (в мобильных браузерах расширений нет)
- Страница товара должна успеть загрузиться (иначе «не нашёл цену» — нажми «Перечитать»)
- Лимит: 50 товаров в день с аккаунта, дубли по артикулу схлопываются
