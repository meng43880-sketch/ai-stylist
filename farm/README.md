# farm/ — 5 выходов для сборщиков (10 минут настройки)

Идея: 5 копий `xray.exe` (ядро из твоего Happ) с 5 разными серверами →
SOCKS `127.0.0.1:20801…20805` → 5 профилей Chrome через SwitchyOmega →
в каждом наше расширение со своим набором. WB видит 5 человек из 5 сетей.

## Шаг 1. Конфиги (5 минут)

1. Скопируй `xray-TEMPLATE.json` → `xray-1.json` … `xray-5.json` (рядом, в `farm/`).
2. В каждый впиши ОДИН свой сервер: UUID, SERVER, PORT, SNI, PBK, SID
   берутся из твоей `vless://` ссылки (разбор — в `_howto` шаблона).
3. Порты: 20801, 20802, 20803, 20804, 20805 — по одному на файл.
4. **Ссылки — только локально.** Файлы `xray-[1-5].json` уже в `.gitignore`,
   в git они не уедут. Никому не пересылай.

## Шаг 2. Запуск

1. Закрой Happ desktop (чтобы не было двойной маршрутизации).
2. Запусти `start-farm.bat` — откроется 5 окон. Ошибка в консоли окна =
   опечатка в его json (порт занят / неверный UUID/ключ).
3. Проверка каждого выхода: в браузере с прокси `127.0.0.1:2080X` открой
   `wildberries.ru` — должен открыться каталог как обычно.

## Шаг 3. Chrome-профили

1. Поставь SwitchyOmega в каждый из 5 профилей: SOCKS5 `127.0.0.1`,
   порт 20801…20805 соответственно, режим — всё через прокси.
2. В каждый профиль загрузи наше `ext/`, впиши backend + ключ.
3. Наборы: профиль 1 → «Набор 1», 2 → «Набор 2», 3 → «Набор 3»,
   4–5 → «Авто» (дни разные — пересечений почти не будет).
4. Стартуй «Собрать» **вразнобой с паузой 2–3 минуты**, не все разом.
   Сервер склеит дубли по id сам.

## Шаг 4. Остановка

`stop-farm.bat` (или закрой 5 окон). Потом можно снова открыть Happ.

## Начни с двух

Не поднимай все 5 сразу: проверь связку на 20801+20802.
Если оба профиля приносят карточки — добавляй остальные.
Лимит разумного: 5 параллельных «человек» с одного ПК — дальше уже
похоже на ферму даже для терпеливого гейта.
